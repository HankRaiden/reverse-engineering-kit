# P2 · Swing failure: a sweep that fails reverses

- **In one sentence:** When price pokes beyond an obvious swing high (low), takes the stops there, and closes back
  inside, the move has failed and often reverses.
- **References:** [Swing Failure MasterClass (PDF, via index)](https://docs.google.com/spreadsheets/d/1bZWhe0WQ3ZXpqYgU1eYJ7ASCrMNWzZ-Bg5j298fhWyk) ·
  [Liquidity Grab](https://x.com/EmperorBTC/status/1514263609597390852)
- **Purpose:** trade against stop hunts.
- **On the chart:** wick beyond the last confirmed swing point, close back inside.
- **Caveat:** context (higher timeframe, volume) matters in the original; our rule ignores it.
- **Measurable:** yes, if swing points are only used once confirmed (look-ahead risk!).
- **Importance:** high.
- **Chairman:** accepted.
