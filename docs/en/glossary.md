# Glossary

| Term | Meaning |
|------|---------|
| **R** | A multiple of the initial risk. +2 R means: won twice what you were willing to lose. |
| **Expectancy** | Average result per trade in R. Above zero means: profitable on average. |
| **Hit rate** | Share of winning trades. Says little on its own. |
| **Profit factor** | Sum of gains divided by sum of losses. 1.0 means break-even. |
| **Drawdown** | How far the account falls below a previous high, in %. |
| **ATR** | Average range per candle. Used for the stop distance. |
| **Look-ahead** | A backtest accidentally uses information that did not exist yet at decision time. |
| **Pre-registration** | Test, metric and rejection criterion are fixed before you see results. |
| **Bootstrap** | The trades are redrawn at random 1,000 times to see how much the result depends on chance. |
| **Confidence interval** | Range in which the true value lies with 95% probability. If it includes zero, nothing is proven. |
| **Deflated Sharpe** | Corrects the Sharpe ratio for how many variants you tried. |
| **Holm correction** | Corrects p-values when several hypotheses are tested at once. |
| **Walk-forward** | Pick parameters on the past, judge them only in the following, unseen period. |
| **Out of sample** | Data that was not used when choosing the rules. |
| **Concentration** | Share of the result that comes from a few trades or symbols. |
| **Time-weighted return** | Measures the strategy regardless of when money was paid in or out. |
| **Money-weighted return** | Measures what the money actually invested really earned. |
| **Paper trading** | Real prices, fictitious trades, no money. |
| **Chairman** | You: the human who decides at the gates and holds every veto. |
| **Gate** | A point in the process where only the chairman may let things pass. |
