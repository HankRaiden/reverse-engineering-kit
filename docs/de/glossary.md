# Glossar

| Begriff | Bedeutung |
|---------|-----------|
| **R** | Ein Vielfaches des anfänglichen Risikos. +2 R heißt: doppelt so viel gewonnen, wie man zu verlieren bereit war. |
| **Erwartungswert (Expectancy)** | Durchschnittliches Ergebnis je Trade in R. Über null heißt: im Schnitt profitabel. |
| **Trefferquote** | Anteil der Gewinner-Trades. Allein wenig aussagekräftig. |
| **Profit-Faktor** | Summe der Gewinne geteilt durch die Summe der Verluste. 1,0 heißt break-even. |
| **Zwischenverlust (Drawdown)** | Wie tief das Konto unter einen vorherigen Höchststand fällt, in %. |
| **ATR** | Durchschnittliche Schwankungsbreite je Kerze. Wird für den Stop-Abstand genutzt. |
| **Look-Ahead** | Ein Backtest nutzt versehentlich Informationen, die es zum Entscheidungszeitpunkt noch nicht gab. |
| **Vorabregistrierung** | Test, Messgröße und Verwerfungs-Kriterium werden festgelegt, bevor man Ergebnisse sieht. |
| **Bootstrap** | Die Trades werden 1.000-mal zufällig neu gezogen, um zu sehen, wie stark das Ergebnis vom Zufall abhängt. |
| **Konfidenzintervall** | Bereich, in dem der wahre Wert mit 95 % Wahrscheinlichkeit liegt. Umfasst er null, ist nichts bewiesen. |
| **Deflated Sharpe** | Korrigiert die Sharpe-Ratio dafür, wie viele Varianten man probiert hat. |
| **Holm-Korrektur** | Korrigiert p-Werte, wenn mehrere Hypothesen gleichzeitig getestet werden. |
| **Walk-Forward** | Parameter auf der Vergangenheit wählen, nur in der folgenden, ungesehenen Zeit bewerten. |
| **Außerhalb der Stichprobe** | Daten, die bei der Wahl der Regeln nicht benutzt wurden. |
| **Konzentration** | Anteil des Ergebnisses, der aus wenigen Trades oder Symbolen stammt. |
| **Zeitgewichtete Rendite** | Misst die Strategie unabhängig davon, wann Geld ein- oder ausgezahlt wurde. |
| **Geldgewichtete Rendite** | Misst, was das eingesetzte Geld tatsächlich verdient hat. |
| **Paper-Trading** | Echte Kurse, fiktive Trades, kein Geld. |
| **Chairman** | Du: der Mensch, der an den Toren entscheidet und jedes Veto hat. |
| **Tor** | Ein Punkt im Ablauf, an dem nur der Chairman weitergeben darf. |
