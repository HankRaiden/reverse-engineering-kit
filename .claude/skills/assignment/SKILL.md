Role: **CIO**. Class: depends on content (ANALYSIS or DECISION).

1. Use `templates/<lang>/assignment.md`; save as `work/assignments/<date>-<title>.md`.
2. Always include F1 (numbers only from `rekit`), F3 (every claim with command + output) and NAK-1…NAK-3.
3. Mark the header `START NOW` for ANALYSIS, `ONLY AFTER CHAIRMAN-GO` for DECISION.
4. Hand over to the CTO. End with the four lines from `AGENTS.md` §5.
